# Structure Isles artwork

Original artwork created for DSA Quest. No Codédex assets, logos, characters or lesson text were used.

| File | Size | Use |
| --- | --- | --- |
| structure-isles-panorama.png | 2172 × 724 RGB PNG | Responsive adventure landscape |
| island-atlas.png | 1983 × 793 RGBA PNG | Ten islands, five columns by two rows |

Created with the built-in image generation tool on 10 November 2026. The panorama was generated from text with an opaque background. The atlas used the generated panorama as a style reference and requested a transparent background.

Generation brief summary: original SNES-era 16-bit pixel art with visible square clusters, lush Caribbean-inspired fantasy floating islands, turquoise waterfalls, violet dusk, glowing lanterns, pink flowering trees, ancient stone portals and a teal hummingbird. The panoramic composition reserves dark, quiet space on the left for live HTML text.

Atlas brief summary: exactly ten distinct floating islands in equal cells, five columns and two rows, fully separated against transparency, without labels or UI. Order: forest campfire; orchard crates; memory runestones; recursion ruins; stack towers; tree temple; harbor; arena; graph bridges; observatory. Match the panorama's pixel palette and lighting.

The files are served locally by the site. The atlas is reused as a CSS background, so selecting chapters does not download separate copies of each island. It is approximately 2.6 MB and the panorama 2.5 MB before HTTP compression. Layout dimensions are reserved before images load. HTML text and controls remain separate from the art.

Pip and guardian sprites in world-art.js are original code-drawn pixel grids. Animations respect the operating system's reduced-motion preference. CSS image-rendering preserves hard edges; these are decorative fantasy illustrations, not instructional structure diagrams.
